# atcoder_test_tool

AtCoderのABCの問題ページのHTMLから入力例と出力例を取り出し、手元のPythonのコードを実行して、出力が出力例と一致するかを判定するWindowsのGUIツール。

## 特徴

- 問題ページのHTMLをコピーすると、入力例と出力例を問題ごとのタブに表示する
- 問題の入力形式から入力を読むコードを推定し、解答のファイルの雛形を作る
- すべての入力例でコードを実行し、出力例と比べて、テストケースごとに合格か不合格かを表示する
- 解答のファイルを保存すると、ツールに表示するコードを更新する
- コメントを除いたコードをクリップボードにコピーする
- AtCoderのサイトには接続しない。ログインもしない

## 必要なもの

- Windows
- tkinterを含むPython 3。python.orgのWindows向けのインストーラーは既定の設定でtkinterを入れる。3.12と3.14の仮想環境で、依存のパッケージを入れてモジュールを読み込めることを確認した
- 依存のパッケージ: keyboard、beautifulsoup4、numpy。numpyは生成する雛形がimportする。仮想環境の外のPythonにもnumpyを入れる。理由は注意の節を参照
- 解答のファイルをVS Codeで開く機能を使うなら、VS Codeの`code`コマンド

## インストール

```
git clone https://github.com/ycookiey/atcoder_test_tool.git
```

## 使い方

1. フォルダの中の`start.bat`を実行する。初回は、同じフォルダに仮想環境`venv`を作り、依存のパッケージを入れてから起動する。`start.bat`を使わない場合は、`pip install keyboard beautifulsoup4 numpy`の後に`python main.py`を実行する
2. ブラウザでABCの問題ページを開き、ページのHTMLをコピーする。ページのソースを表示して、全体をコピーすればよい。AtCoderの問題ページに特有のタグを含む文字列をコピーすると、ツールが自動で貼り付けて解析する。自動で貼り付けられないときは、「HTML入力」タブの「クリップボードから貼り付け」を押す
3. 解析が終わると、`<問題の記号>: <問題名>`の名前のタブが開き、入力例と出力例を表示する
4. 解答のファイル`<回の番号><問題の記号>.py`が無ければ、タブの「ファイルを生成」を押す。例えばABC421のB問題なら`421B.py`になる。ファイルはツールを起動したフォルダに作り、VS Codeで開く
5. F5を押すか、「テスト実行 (F5)」を押すと、すべての入力例で解答のファイルを実行し、結果を表示する
6. 「コピー」を押すかCtrl+Cを押すと、コメントを除いたコードをクリップボードにコピーする

| キー | 動作 |
|---|---|
| F5 | テストを実行する |
| Ctrl+C | コメントを除いたコードをコピーする |
| Ctrl+Tab、Ctrl+Shift+Tab | 次のタブ、前のタブに切り替える |
| Alt+H | ほかのアプリを使っている間も、ツールのウィンドウを前面に出す |

## 注意

- 解答のファイルを作ってテストを実行できるのは、ABCの問題だけ。問題ページの中の、見出しが「入力例」と「出力例」の節を読む
- 出力を判定するときは、実際の出力と出力例の前後の空白を除き、大文字と小文字を区別せずに文字列で比べる。小数の誤差は許さない。ツールで合格と表示されても、AtCoderでは不正解になることがある
- 解答のファイルは`python`の名前で探したPythonで実行する。WindowsはPATHより先に、ツールを動かしているPython本体のフォルダを探す。そのため、`start.bat`で仮想環境`venv`から起動しても、解答は仮想環境の外のPythonで実行する。仮想環境の外のPythonにnumpyが無いと、雛形の`import numpy`で、すべてのテストが失敗する
- テストは1件ごとに5秒で打ち切り、最大4件を同時に実行する
- コメントを除くときは、各行の最初の`#`から行末までを消す。文字列の中の`#`も消える
- 解答のファイルがあるとき、ツールの中でCtrl+Cを押すと、選んだ文字ではなく、コメントを除いたコードをコピーする
- ツールを起動している間は、0.5秒ごとにクリップボードの文字列を読む
- Alt+Hでウィンドウを前面に出すため、keyboardのパッケージがすべてのキー入力を受け取るフックを登録する

## アンインストール

フォルダを削除する。ツールは設定のファイルを作らない。解答のファイルも同じフォルダにあるので、残すなら先に移す。
